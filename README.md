# Internship-task-4

Dashboard Design

About

In this task, I designed an interactive Sales Performance Dashboard using Power BI to analyze sales, profit, orders, and business trends.

Tools Used

- Power BI

Dataset

- Sales Dataset

Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Profit Percentage KPI
- Sales by Category
- Profit by State
- Monthly Sales Trend
- Category Filter for interactivity

Key Insights

- Office Supplies recorded the highest sales.
- New York generated the highest profit.
- Sales reached their peak in December.
- September showed the lowest sales performance.
- The overall profit percentage was 26.2%.
